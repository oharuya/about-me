# about-me

奥元遥矢についての自己紹介サイトです

**アピールポイント**
・ワンレッドとゴールドを使用した高級感と統一感のあるデザインになるよう工夫しました
・画像を配置することで視覚的に楽しみつつ訪問者の理解を深められるようにしました
・実際に音楽は流れませんが、よくあるサブスクリプション音楽アプリのような機能を実装しました。
・次回できればフリー素材の音楽などを自由に選んで楽しみつつ閲覧できるサイトにしたいです

**苦労したポイント**
・どうしても直感的にレイアウトや色の調整ができなかったのでそこに一番時間がかかり何度も試行錯誤しました
・html,cssはもちろん、jsはもっての外触れてこなかったので理解と動作確認にも時間がかかりました

**改善ポイント**
・スマホサイズにしたときに画像の大きさがばらばらで見にくいので色んな端末でも見やすいレイアウトに変えたいです
・ロゴを図形をcss上で細かく作ってしまいとても時間がかかったので次回からはロゴは写真ファイルで掲載したいです
